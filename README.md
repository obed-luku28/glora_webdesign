# Glora – Agence de création de sites web

Site vitrine moderne, sobre et performant pour l'agence **Glora**.

## 🚀 Fonctionnalités

- **Design épuré et responsive** : pensé mobile-first, compatible tablette et desktop.
- **Réalisations avec captures automatiques** : intégration dynamique des aperçus de sites web via l'URL (sans besoin d'importer manuellement des captures).
- **Icône Font Awesome au survol** : bouton interactif avec redirection vers le site web créé au clic.
- **Micro-interactions et animations** : apparition fluide au défilement (*reveal*), menu burger mobile animé, transitions CSS soignées.
- **Contact direct** : intégration WhatsApp, Email et réseaux sociaux.
- **Performance & SEO** : code HTML5 sémantique, CSS moderne vanille, JavaScript léger sans dépendance lourde.

## 📁 Structure du projet

```
├── index.html       # Structure HTML5 du site
├── style.css        # Feuille de styles CSS (variables, typographie, mise en page, animations)
├── script.js       # Logique JavaScript (menu burger, capture auto des réalisations, scroll reveal)
└── README.md        # Présentation du projet
```

## 🛠️ Utilisation locale

Ouvrez simplement le fichier `index.html` dans votre navigateur ou lancez un serveur local :

```bash
# Exemple avec Python
python -m http.server 3000
```
